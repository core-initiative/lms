# Project Brief: Frappe Learning (Frappe LMS)

## Overview
Frappe Learning is an open-source Learning Management System (LMS) designed to provide a modern, user-friendly platform for structured online education. It enables organizations and individuals to create, manage, and deliver courses with a focus on simplicity, extensibility, and a superior user experience compared to legacy LMS platforms.

## Core Requirements
- **Course Management:** Support for a hierarchical structure (Courses → Chapters → Lessons).
- **Live Classes:** Integration with Zoom for real-time sessions, batch management for learners.
- **Quizzes & Assignments:** Multiple question types, submission handling, and instructor evaluation.
- **Certification:** Automated or custom certificate generation upon course or batch completion.
- **User Profiles:** Customizable profiles with extensible tabs and widgets.
- **Extensibility:** Plugin architecture for profile tabs, page extensions, and widgets.
- **SCORM Support:** Ability to render and serve SCORM-compliant content.
- **Job Openings:** Integration for job opportunities and notifications.
- **Modern UI:** Responsive, SPA frontend using Vue 3 and Frappe UI.
- **API Integrations:** Unsplash for images, Zoom for live classes, Razorpay for payments.

## Goals
- Provide a simple, intuitive alternative to complex LMS platforms like Moodle.
- Enable rapid course creation and management for educators and organizations.
- Foster community-driven development and extensibility.
- Ensure a seamless, modern user experience for both learners and instructors.

## Scope
- Backend built on Frappe Framework (Python), leveraging hooks, plugins, and widgets for extensibility.
- Frontend built with Vue 3, Pinia, TailwindCSS, and Frappe UI, supporting SPA navigation and dynamic content.
- Automated setup and deployment via Docker and Frappe Cloud.
- Comprehensive documentation and community support channels.
