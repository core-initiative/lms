# Product Context: Frappe Learning (Frappe LMS)

## Why This Project Exists
Frappe Learning was created to address the complexity and poor user experience found in traditional Learning Management Systems (LMS) like Moodle. The founders needed a platform for Mon.School (FOSS United) that was easy to use, quick to set up, and provided a modern, intuitive interface for both educators and learners. Existing solutions were cumbersome, with lengthy forms and confusing navigation, making course creation and management unnecessarily difficult.

## Problems Solved
- **Complexity of Existing LMS:** Simplifies course creation, management, and delivery compared to legacy systems.
- **Poor User Experience:** Offers a clean, modern UI with logical navigation and responsive design.
- **Lack of Extensibility:** Provides a plugin and widget system for easy customization and extension.
- **Fragmented Learning Tools:** Integrates live classes, quizzes, assignments, and certification in one cohesive platform.
- **Limited Community Involvement:** Encourages open-source contributions and community-driven enhancements.

## How It Should Work
- **For Educators:**
  - Quickly create and structure courses with chapters and lessons.
  - Schedule and manage live classes (Zoom integration).
  - Design quizzes and assignments with flexible question types.
  - Grant certificates automatically or manually.
  - Customize user profiles and extend functionality via plugins/widgets.
- **For Learners:**
  - Browse and enroll in courses easily.
  - Attend live classes and complete lessons at their own pace.
  - Take quizzes, submit assignments, and track progress.
  - Receive certificates upon completion.
  - Access a modern, mobile-friendly interface.

## User Experience Goals
- **Simplicity:** Minimize steps and cognitive load for all user actions.
- **Clarity:** Clear navigation, logical structure, and helpful feedback throughout the platform.
- **Responsiveness:** Fast, mobile-friendly UI with SPA navigation.
- **Extensibility:** Easy to customize and extend for different organizations or use cases.
- **Community-Driven:** Foster a welcoming environment for contributors and users alike.
